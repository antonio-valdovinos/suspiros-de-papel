# Suspiros de Papel

Landing page para Suspiros de Papel — detalles personalizados con alma.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Estructura
src/
  app/          → rutas y layout
  components/   → UI, layout, sections
  constants/    → datos estáticos (servicios, portfolio, site)
  hooks/        → useScrollReveal
  types/        → tipos compartidos (Fase 2: sistema de pedidos)

## Correr en desarrollo
npm run dev
